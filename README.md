# Arcane Artistry
[![Modrinth](https://img.shields.io/badge/Download_Now-Arcane_Artistry-4034eb?style=for-the-badge)](https://modrinth.com/mod/arcane-artistry)

Arcane Artistry is a Minecraft magic mod that aims at turning the act of casting spells into a more interactive experience.
Harnessing the magical powers of lapis lazuli spells are cast by moving the staff into the respective pattern e.g. up, down, left, right for a fireball.
